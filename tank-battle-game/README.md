# 坦克大战游戏

一个基于HTML5 Canvas和JavaScript的2D坦克大战游戏。

## 游戏特色

- 🎮 经典2D坦克对战玩法
- 🤖 智能AI敌坦克
- 💥 真实的战斗系统和爆炸效果
- 🎯 精确的碰撞检测
- 📱 响应式设计，支持不同屏幕尺寸
- 🏆 分数和关卡系统

## 游戏控制

- **WASD** - 移动坦克
- **鼠标** - 瞄准方向
- **鼠标左键** - 射击
- **空格键** - 暂停/继续游戏

## 游戏目标

- 击败所有敌坦克
- 避免被敌人击中
- 获得最高分数
- 挑战更高关卡

## 如何运行

### 方法1: 直接打开
在浏览器中直接打开 `index.html` 文件

### 方法2: 使用本地服务器
```bash
# 进入游戏目录
cd tank-battle-game

# 启动Python HTTP服务器
python3 -m http.server 8080

# 在浏览器中访问
# http://localhost:8080
```

## 技术栈

- **HTML5 Canvas** - 游戏渲染
- **原生JavaScript** - 游戏逻辑
- **CSS3** - 样式和动画
- **响应式设计** - 适配不同设备

## 游戏架构

- **游戏引擎** - 核心游戏循环和状态管理
- **对象系统** - 坦克、子弹、障碍物类
- **物理系统** - 碰撞检测和运动学
- **AI系统** - 敌坦克智能行为
- **UI系统** - 用户界面和状态显示

- 面向对象的代码架构
- 高性能的Canvas渲染
- 流畅的60fps游戏体验
- 模块化的代码设计
- 现代化的游戏UI设计
